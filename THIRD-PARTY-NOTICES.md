## The Office Open XML standard

`src/ooxml/presets-data.js` holds the preset shapes' geometry (their guides and paths) from the Office Open XML
standard, ECMA-376 Part 1 (5th edition), file `presetShapeDefinitions.xml`, copyright Ecma International, which
publishes the standard free of charge for anyone to use; `tools/presets/build-presets.py` makes the file from it.

## Fonts and Microsoft material

The repository contains no Microsoft code, templates, documents or fonts. `src/fonts/` bundles open-licensed fonts with
the same character widths as Microsoft's, for computers without them (used only when the host imports
`open-docx-editor/fonts.css`):

| Font | Stands in for | License |
|---|---|---|
| Carlito | Calibri | SIL Open Font License 1.1 |
| Caladea (its 2013 release) | Cambria | Apache License 2.0 |
| Arimo (as Liberation Sans) | Arial | SIL Open Font License 1.1 |
| Tinos (as Liberation Serif) | Times New Roman | SIL Open Font License 1.1 |
| Cousine (as Liberation Mono) | Courier New | SIL Open Font License 1.1 |

Their license texts are in `src/fonts/LICENSE.md`. Beside them, `src/fonts/files/` holds eight small fonts standing in
for Aptos and Aptos Display: Source Sans 3's letters (Adobe), each narrowed or widened to Aptos's width and scaled to its
x-height (made by `tools/fonts/build-aptos.mjs`), a modified version of Source Sans 3 under its SIL Open Font License
1.1, named without its Reserved Font Name. The editor loads these files from jsDelivr (or the host's copy) only when a
document uses a font the computer lacks. For
other fonts, the stylesheet refers to a stand-in installed on the computer by name (`local()`), sized to the
original's widths. `src/engine/metrics.json` holds measurements (ascent,
descent, line gap per em) of common fonts, facts about the fonts rather than any part of them.

The open-metric-fonts fonts (https://github.com/open-metric-fonts/open-metric-fonts, SIL Open Font License 1.1) are not
in this package: the editor loads them at run time from npm's `@open-metric-fonts` packages on jsDelivr (or the host's
copy) for fonts a document uses that the computer lacks. `src/fonts/omf.js` lists, from those packages (made by
`tools/fonts/build-omf.py`), which Microsoft family each stands in for, its font files and the characters each holds,
and the line height its metrics give.

The test documents in `test/fixtures` are generated by the scripts beside them. The documents the layout was measured
against are private and not in the repository.
