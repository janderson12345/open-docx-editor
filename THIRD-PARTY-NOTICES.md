## Fonts and Microsoft material

The repository contains no Microsoft code, templates, documents or fonts. `src/fonts/` bundles open-licensed fonts with
the same character widths as Microsoft's, for computers without them (used only when the host imports
`open-docx-editor/fonts.css`):

| Font | Stands in for | License |
|---|---|---|
| Carlito | Calibri | SIL Open Font License 1.1 |
| Caladea (its 2013 release) | Cambria | Apache License 2.0 |
| Arimo (as Liberation Sans) | Arial | SIL Open Font License 1.1 |
| Tinos (as Liberation Serif) | Times New Roman | SIL Open Font License 1.1 |
| Cousine (as Liberation Mono) | Courier New | SIL Open Font License 1.1 |

Their license texts are in `src/fonts/LICENSE.md`. For other fonts, the stylesheet refers to a stand-in installed on
the computer by name (`local()`), sized to the original's widths. `src/engine/metrics.json` holds measurements (ascent,
descent, line gap per em) of common fonts, facts about the fonts rather than any part of them.

The test documents in `test/fixtures` are generated by the scripts beside them. The documents the layout was measured
against are private and not in the repository.
